# Passage for iPhone

Passage brings your [passage](https://github.com/FiloSottile/passage) password store to iPhone. Every entry is a file encrypted with [age](https://age-encryption.org), and the store lives where you choose: a private GitHub repository, any git server, or a folder in the Files app. No accounts, no servers, no tracking.

- Keys in the Secure Enclave, unlocked with Face ID; YubiKeys and imported age keys work too
- Post-quantum encryption by default, compatible with age 1.3
- AutoFill for passwords, one-time codes and passkeys
- Open source: [github.com/elohmeier/passage-app](https://github.com/elohmeier/passage-app)
