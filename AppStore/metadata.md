## Description

Passage brings your passage password store to iPhone. Every entry is a file encrypted with age, a modern, audited encryption format, and the store lives where you choose: a private GitHub repository, any git server, or a folder in the Files app. No accounts, no servers, no tracking.

KEYS THAT STAY PUT
• Your key is created in the Secure Enclave and can't be copied off the device
• Face ID or your passcode unlocks it; choose how long an unlock lasts
• Post-quantum encryption (ML-KEM) by default, compatible with age 1.3
• Use a YubiKey over NFC or USB-C, or import existing age keys

WORKS WITH YOUR STORE
• Compatible with passage and age on your computers
• Connect a GitHub repository in a few taps: Passage adds a deploy key that only reaches that one repository
• Clone any git server over HTTPS or SSH, or open a folder in Files or iCloud Drive
• Edits sync automatically; conflicting edits are kept side by side, never lost
• Start a new store from your phone with a recovery key you keep

AUTOFILL EVERYWHERE
• Passwords and one-time codes in Safari and apps
• Passkeys: create and sign in, stored in your store like any other entry
• Import from Apple Passwords and other apps
• Shortcuts and Control Center: copy a code, search, sync

PRIVATE BY DESIGN
• No analytics, no third-party code, no account
• Changes to who can read your store are shown for approval
• The screen is hidden in the app switcher and while recording

Passage is independent and not affiliated with the authors of age or passage.
